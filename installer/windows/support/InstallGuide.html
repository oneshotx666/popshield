PopShield

Windows install guide

What the installer already did

The installer copied PopShield into your local app data folder and should have opened the exact extension folder you need, along with your browser's extensions page.

Finish the install

  1. In Chrome or Edge, open the extensions page.
  2. Turn on Developer mode.
  3. Click Load unpacked.
  4. Select the Extension folder the installer opened.

Installed location

If you need to open it manually later, look under:
%LocalAppData%\PopShield\Extension
